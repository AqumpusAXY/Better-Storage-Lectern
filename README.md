## 📖 Overview

Better Storage Lectern is an addon mod for Ars Nouveau that enhances the Storage Lectern interface. It improves player experience by adding configuration options for many features of the Storage Lectern GUI.

## ✨ Features

### Core Features

- **Single Row Scrolling**: Configurable row-by-row scrolling for precise browsing
- **Optional Auto-Focus Search Bar**: 
  - Auto-focus search field when GUI opens
  - Auto-focus search field on key press
- **Optional Search Content Save**: Optionally save previous search content for quick filter restoration
- **Inverted Scroll Wheel by Default**: Provides a more intuitive scrolling experience (Note: If you've launched Minecraft with Ars Nouveau before installing this mod, please modify the setting in Ars Nouveau's config file at `config\ars_nouveau-client.toml:overlays.invertLecternScrolling`)

## ⚙️ Configuration

All features can be customized through the client configuration file:

| Configuration Key | Default Value | Description |
|-------------------|---------------|-------------|
| `enable_single_row_scrolling` | `true` | Enable single row scrolling mode |
| `auto_focus_search_field_on_opened` | `false` | Auto-focus search field when GUI opens |
| `auto_focus_search_field_on_key_pressed` | `false` | Auto-focus search field on key press |
| `save_search_field_content` | `false` | Save search field content |

## 🎮 Usage

After installation, all improvements will automatically apply to the Ars Nouveau Storage Lectern interface. You can adjust feature behavior by modifying the configuration file.

### Accessing Configuration

In-game, you can access the configuration by:
1. Open Main Menu → Mods → Find "Better Storage Lectern"
2. Click the configuration button to enter settings

## 📖 简介

Better Storage Lectern 是一个为《新生魔艺》(Ars Nouveau) 模组中的存储讲台(Storage Lectern)提供增强功能的附属模组。它通过为存储讲台GUI的许多功能添加配置选项来提升玩家使用体验。

## ✨ 功能特性

### 核心功能

- **单行滚动**: 可配置的逐行滚动功能，使物品浏览更加精确
- **可选的搜索栏自动聚焦**: 
  - 打开GUI时自动聚焦搜索栏
  - 按键时自动聚焦搜索栏
- **可选的搜索内容保存**: 可选择保存上次搜索的内容，方便快速恢复筛选状态
- **默认反转滚轮**: 默认启用滚轮方向反转，提供更符合直觉的滚动体验（注意：如果在装载此mod前启动过装载有新生魔艺的Minecraft，请于新生魔艺的配置文件中修改，位置为 `config\ars_nouveau-client.toml:overlays.invertLecternScrolling`）

## ⚙️ 配置选项

所有功能都可以通过客户端配置文件进行自定义：

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `enable_single_row_scrolling` | `true` | 启用单行滚动模式 |
| `auto_focus_search_field_on_opened` | `false` | 打开GUI时自动聚焦搜索栏 |
| `auto_focus_search_field_on_key_pressed` | `false` | 按键时自动聚焦搜索栏 |
| `save_search_field_content` | `false` | 保存搜索栏内容 |

## 🎮 使用方法

安装模组后，所有改进将自动应用于新生魔艺的存储讲台界面。您可以通过修改配置文件来调整各项功能的行为。

### 访问配置

在游戏中，您可以通过以下方式访问配置：
1. 打开主菜单 → Mods → 找到 "Better Storage Lectern"
2. 点击配置按钮进入设置界面
